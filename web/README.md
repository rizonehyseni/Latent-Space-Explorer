# Molecular Latent Space Explorer Frontend

The frontend is an interactive scientific interface for exploring molecular representations learned by the QM9 fingerprint VAE.
The application loads versioned browser artifacts generated by the Python backend and visualizes all 10,000 aligned QM9 molecules.

## Features

- interactive PCA and UMAP molecular maps;
- WebGL rendering for 10,000 points;
- molecular-property coloring;
- zooming, panning, and hover information;
- molecule selection and ID search;
- train, validation, and test filtering;
- selected-molecule coordinates, SMILES, and properties;
- latent-neighbor distance and Tanimoto comparison;
- loading, empty-result, error, and schema-validation states;
- high-resolution projection export through the Plotly toolbar.

## Run locally

From the `web` directory:

```powershell
npm install
npm run dev
```

Vite prints the local URL in the terminal. The application expects the generated browser artifacts under `web/public/data/`.

## Regenerate browser data

From the repository root with the Python environment activated:

```powershell
python -m backend.export_web_data --config configs/qm9_web_export.yaml
```

The export validates molecule alignment across PCA, UMAP, properties, dataset splits, and neighbor records before writing the browser JSON files. See [WEB_DATA_EXPORT.md](../docs/WEB_DATA_EXPORT.md) for the schema and integrity checks.

## Validate the frontend

From the `web` directory:

```powershell
npm run lint
npm run build
```

## Interpretation boundaries

- PCA and UMAP are two-dimensional views of a 16-dimensional latent representation and do not preserve every high-dimensional relationship.
- Neighbor records are available for the 1,000 held-out test queries and use training molecules as references.
- Tanimoto similarity measures overlap between Morgan fingerprints; it is not proof of equivalent biological activity or chemical behavior.
- The VAE reconstructs fingerprints rather than directly decoding latent vectors into valid molecular structures.
