# Molecular Latent Space Explorer Frontend

This directory contains the frontend foundation for the future Molecular Latent Space Explorer.

## Current status

The frontend currently provides a React and Vite application foundation.

It is not yet connected to trained model artifacts, QM9 metadata, latent coordinates, or molecular visualizations.

## Planned role

The frontend will become the interactive research interface for the project.

Future capabilities include:

- 2D and 3D latent-space visualization;
- molecule selection and inspection;
- property-colored latent projections;
- nearest-neighbor exploration;
- molecular descriptor panels;
- latent interpolation demonstrations;
- research figure and experiment-result presentation.

## Planned technology stack

| Area | Planned technology |
|---|---|
| Application framework | React |
| Development tooling | Vite |
| Programming language | TypeScript |
| Styling | CSS variables and a minimal design system |
| Scientific charts | Observable Plot, D3, or similar lightweight chart library |
| 3D latent-space rendering | Three.js through React Three Fiber |
| Molecular structure rendering | RDKit-generated assets or a browser-compatible molecular viewer |
| Data loading | Versioned JSON or binary latent-space artifacts generated by the backend |
